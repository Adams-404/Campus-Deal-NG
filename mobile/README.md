# Campus Deal Mobile

This is the mobile application for Campus Deal, built to complement the web platform.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator (macOS) or Android Emulator

### Initialization (Recommended)
To initialize the project with Expo and TypeScript, run the following in this directory:
```bash
npx create-expo-app@latest -t expo-template-blank-typescript .
```

### Planned Tech Stack
- **Framework**: Expo / React Native
- **Language**: TypeScript
- **State Management**: TanStack Query (React Query)
- **Backend**: Supabase (Shared with Web)
- **UI**: NativeWind (Tailwind CSS for React Native)
- **Navigation**: Expo Router (File-based navigation)
