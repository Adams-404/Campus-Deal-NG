# Campus Deal Features & Functionality

The following features are currently implemented in the web application and should be ported to the mobile version:

## Core Modules

### 1. Marketplace (Home/Index)
- **Browse Listings**: Categorized view of items for sale.
- **Search**: NLP-powered search bar for finding items.
- **Item Details**: View item descriptions, prices, images, and seller info.
- **Sell Item**: Upload images/videos, set category, price, and condition.
- **Saved Items**: Bookmark items for later viewing.
- **My Listings**: Manage your own active and sold items.

### 2. Gigs (Campus Jobs)
- **Post a Gig**: Request help for tasks (e.g., "Help with laundry", "Need a tutor").
- **Apply for Gigs**: Students can apply for posted tasks.
- **Gig Management**: Track applications and gig status (open, filled, completed).
- **Gig Reviews**: Leave feedback for gig performers.

### 3. Messaging System
- **Real-time Chat**: Secure messaging between buyers and sellers.
- **Conversation Management**: Inbox view of all active chats.
- **Contextual Messaging**: Link messages to specific items or gigs.

### 4. Wallet & Transactions
- **Balance Tracking**: View current wallet balance (NGN).
- **Transaction History**: History of deposits, withdrawals, and payments.
- **Withdrawals**: Functionality to move funds from wallet to bank account.

### 5. Campus Services
- **Events**: View and post upcoming campus events.
- **News**: Local campus updates and announcements.
- **Study Resources**: Share notes and academic materials.
- **Lost & Found**: Portal for reporting and finding lost items.
- **Roommates**: Finder for shared accommodation.
- **Delivery Services**: Coordination for on-campus deliveries.

### 6. User Profiles & Verification
- **User Profiles**: View public profiles of other students.
- **KYC (Know Your Student)**: Verification process via student IDs/emails.
- **Leaderboard**: Referral-based gamification system.
- **Settings**: Manage profile info, passwords, and preferences (Dark/Light mode).

### 7. AI Assistant
- **NLP Support**: AI-driven help and search capabilities using Google Gemini.

### 8. Notifications
- **In-app Notifications**: Alerts for new messages, gig updates, and system news.
