
# GSU Market Hub

![GSU Market Hub](https://gsu-market-hub.vercel.app/logo.png)

GSU Market Hub is a secure online marketplace designed specifically for students of Gombe State University. Our platform enables students to buy, sell, and trade items within the campus community safely and efficiently.

## 🌐 Live Website

**URL**: [GSU Market Hub](https://gsu-market-hub.vercel.app)

## 🎯 Purpose & Vision

GSU Market Hub was created to address the challenges students face when trying to sell or purchase items on campus. We provide a centralized, secure platform that:

- Connects buyers and sellers within the GSU community
- Ensures transactions happen between verified students
- Eliminates the need for third-party marketplaces
- Reduces scams and fraudulent activities
- Promotes a circular economy within the campus

## ✨ Key Features

### 🔒 Security & Trust
- **Verified Users**: All users must verify their GSU student status
- **KYC Process**: Know Your Customer verification ensures user authenticity
- **Safety Tips**: Built-in safety guidelines for secure transactions
- **Reporting System**: Flag suspicious listings or users

### 🛍️ Shopping Experience
- **Smart Categories**: Browse items by department, type, or price
- **Advanced Search**: Find exactly what you need quickly
- **Saved Items**: Bookmark items of interest for later viewing
- **Smart Recommendations**: Discover relevant items based on your interests

### 💬 Communication
- **Direct Messaging**: Chat securely with sellers or buyers
- **Notification System**: Get alerts for messages, offers, or status changes
- **Real-time Updates**: See when messages are read or when listings change

### 📱 User Experience
- **Responsive Design**: Optimized for all devices from mobile to desktop
- **Dark/Light Mode**: Choose your preferred viewing experience
- **Intuitive Interface**: Easy to navigate and use
- **Real-time Updates**: See new listings as they're posted

### 📝 Listings Management
- **Easy Listing Creation**: Add items for sale in minutes
- **Rich Media Support**: Upload multiple images and videos
- **Detailed Descriptions**: Space for comprehensive item details
- **Price Negotiation**: Set fixed prices or allow offers

## 🛠️ Technologies Used

GSU Market Hub is built with modern, robust technologies:

- **Frontend**: React, TypeScript, Tailwind CSS
- **UI Components**: shadcn/ui for consistent, accessible components
- **State Management**: React Context API and Hooks
- **Backend & Database**: Supabase (PostgreSQL)
- **Authentication**: Secure email/password and social login
- **Storage**: Supabase Storage for images and videos
- **Deployment**: Vercel for continuous deployment

## 🚀 Getting Started

### For Users
1. Visit [GSU Market Hub](https://gsu-market-hub.vercel.app)
2. Create an account using your GSU email address
3. Complete your profile and verification
4. Start browsing or listing items!

### For Developers
If you want to contribute to the development:

```bash
# Clone the repository
git clone https://github.com/yourusername/gsu-market-hub.git

# Install dependencies
npm install

# Start development server
npm run dev
```
